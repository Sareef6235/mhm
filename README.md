# SmartID Pro - Core PHP Digital ID Card Management System

A cPanel-ready smart QR digital ID card management system built with Core PHP, MySQL, Bootstrap 5, JavaScript, AJAX-ready endpoints and premium responsive UI.

## Install
1. Upload files to cPanel `public_html`.
2. Create a MySQL database and import `database/schema.sql`.
3. Edit `config/config.php` or set environment variables for database credentials.
4. Login at `/login.php` using `admin@example.com` / `password`, then change the password immediately.

## Included Modules
Dashboard, members, digital ID cards, QR/barcode, departments, classes, categories, attendance, payments, certificates, documents, visitors, verification, reports, analytics, settings, users, roles, permissions, activity logs, backup and website settings.

## Security
Prepared PDO statements, CSRF tokens, password hashing, secure session cookies, permission hooks, upload validation, XSS escaping and audit logging are included.
